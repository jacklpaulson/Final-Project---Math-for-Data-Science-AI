# Calculus Behind Neural Networks

A step-by-step walkthrough of the math behind training a neural network. Using a wafer defect prediction example, this project follows a forward pass, calculates loss, applies the chain rule through backpropagation, and updates the weights and biases with gradient descent.

## Project Materials

- **PowerPoint presentation:** Explains neural network concepts and walks through the example with equations and explanations.
- **Worked math PDF:** Contains the handwritten calculations for the forward pass, loss, gradients, and parameter updates.
- **Word write-up:** Provides a typed explanation of the worked example.

## Topics Covered

- Weights, biases, and sigmoid activation
- Matrix multiplication and the forward pass
- Binary cross entropy loss
- Partial derivatives and the chain rule
- Backpropagation and gradient descent

The example uses three inputs, two hidden layers with three and two neurons, and one output neuron.
